# Jolly Muse · 公开网页部署

此仓库仅包含浏览器运行资源，网页入口发布到 https://sugarvei.github.io/jolly-muse-site/ 。完整可编辑工程、原生 Blender 模型和原始渲染资料保存在所有者的独立私有仓库。

`site/` 是 Jolly Muse v3.1.0 的静态网页，保留姿态跟随、触控、暂停、回正、近景和 D4 三维探索。由 GitHub Actions 上传该目录并部署到 GitHub Pages，不安装前端依赖，也不包含模型母版。

v3.1.0 将 95 个原生关键姿态打包为 5 张常驻图集，连续转头通过邻近姿态插值，不再逐角度等待网络请求。默认在桌面使用 480×640 动作画面，手机或较低内存设备使用 360×480；停稳后按需渐入原有 720×960 高清姿态。精细模式加载 720×960 动作图集；流畅模式使用 300×400。保留全部 1,241 个原有姿态文件和原模型来源。

图集可用 `python tools/build-motion-atlases.py` 从本仓库的现有帧资源重新生成（需要 Pillow）。新增或更新播放器时同步修改入口脚本版本参数，避免访客继续读取浏览器缓存中的旧播放器。
