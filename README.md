# Jolly Muse · 高清互动桌面与网页

当前播放器版本为 **3.5.0**。公开页面：https://sugarvei.github.io/jolly-muse-site/?v=3.5.0 。此仓库只发布浏览器运行资源，可编辑 Blender 母版保存在所有者的私有工程仓库。

## v3.5.0 清晰度改进

- 使用 Blender Cycles 重新渲染，原生相机画布由 720×960 提高到 **1440×1920**，采样由 16 提高到 **96**；不是对旧图放大或 AI 补细节。
- 128 组原生毛发原型的线径调整为原来的 88%，细化纤维高光；保留角色形体、卷毛中心线、毛根、颜色、脸部与耳机造型。
- 降低像素滤波宽度，采用更严格的自适应采样阈值及准确预滤波降噪。关闭景深，保持脸部和身体清晰。
- 95 个原生头颈姿态覆盖原有转头范围。静止身体由正面高清渲染统一，头颈不与正面身体在运行时交叉混合。批量渲染只重复计算包含完整运动区域的上部 65%；其余身体像素来自同一次正面采样。
- 无损 WebP 提供 480、720、1080、1440 四个宽度的资源档位。自动画质按屏幕像素、设备内存和 GPU 最大纹理尺寸选择；交互过程中不因转头而切换到低清图。
- 位移图从新版姿态重新计算；仍是图像位移近似，并非浏览器实时运行完整 Blender 模型。

## 显示与资源

精细模式最高使用 1440×1920，均衡模式为 1080×1440，流畅模式为 480×640。手机及低内存设备自动选择 720×960；显卡纹理限制可能降低可用档位。桌面高分屏、1920px 及以上窗口自动使用最高档位。

最高档位常驻色彩图集约 1055 MiB，另有位移图和背景纹理；1080 档约 593 MiB，720 档约 264 MiB，480 档约 117 MiB。不同档位分别下载对应资源。初次高清加载较大，首次纹理上传完成后才开启交互；之后转头不需要网络请求。静止时停止重绘。

全景构图保留头顶、耳机、手脚；近景可主动放大。完整三维探索入口继续独立提供实时浏览。

## 验证与部署

`node --test tests/*.test.mjs` 验证姿态覆盖、构图、高清资源完整性、无损编码和画质选择。GitHub Actions 先运行这些检查，再将 `site/` 发布到 GitHub Pages。

发布前检查桌面和手机视口的鼠标跟随、触控、暂停、回正、近景、画质切换以及加载后断网交互。浏览器手机模拟不代表实体手机性能。

旧版 3.4.0 资源保留用于回溯。修改播放器时同步更新脚本与资源版本参数，避免旧缓存。
