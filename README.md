# Jolly Muse · 公开网页部署

此仓库仅包含浏览器运行资源，网页入口发布到 https://sugarvei.github.io/jolly-muse-site/ 。完整可编辑工程、原生 Blender 模型和原始渲染资料保存在所有者的独立私有仓库。

`site/` 是 Jolly Muse v3.2.0 的静态网页，保留姿态跟随、触控、暂停、回正、近景和 D4 三维探索。由 GitHub Actions 上传该目录并部署到 GitHub Pages，不安装前端依赖，也不包含模型母版。

v3.2.0 修复 v3.1.0 多姿态透明叠加造成的双眼、双嘴和轮廓重影。现在每帧只显示一个原生姿态，通过 WebGL 位移映射移动像素，连续跟随目光；不混合不同人脸，也不在停稳后换入另一张细节图。95 个原生姿态及位移图加载完成后常驻，交互过程无需继续请求姿态资源。静止时停止重绘。

图像由原始 PNG 重新生成。默认桌面使用 720×960、手机使用 600×800；浏览器报告内存不超过 4 GB 时自动使用 480×640。精细、均衡、流畅模式分别使用 720×960、600×800、480×640；最高画布像素比为 2。初次加载约 15.4 MiB，纹理内存约为桌面 297 MiB、手机 216 MiB，低内存模式约 150 MiB（不含浏览器其他内存）。不支持 WebGL 的浏览器退回 Canvas 2D 单姿态播放，角度变化会更粗，但不叠加重影。

构图根据所有原生姿态的可见边界计算，默认全景保留头顶、耳机、手脚，并避开导航和文字。近景仍支持主动放大。位移是近似的图像变形，不等于重新渲染三维模型；大角度遮挡和毛绒细节仍有近似误差。

重新生成本版图集需要 Pillow、NumPy、OpenCV 和原始 95 张 720×960 PNG：`python tools/build-warp-atlases.py --renders <原始渲染目录>`。原始文件名为 `p00_y00.png` 至 `p04_y18.png`。历史 1,241 张姿态文件继续保留，但当前首页不使用其中的光流混合图。更新播放器时同步修改入口脚本版本参数，避免读取旧缓存。

验证：`node --test tests/*.test.mjs`；另在 Chrome 检查连续鼠标跟随、触控、暂停、回正、近景、画质切换、减少动态效果、加载后断网，以及 1440×1000、390×844、320×568、844×390 的中间角度截图。浏览器手机模拟不代表实体手机性能。
