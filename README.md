# Jolly Muse · 公开网页部署

此仓库仅包含浏览器运行资源，网页入口发布到 https://sugarvei.github.io/jolly-muse-site/ 。完整可编辑工程、原生 Blender 模型和原始渲染资料保存在所有者的独立私有仓库。

`site/` 来自 Jolly Muse v3.0.1 的静态构建，保留高清姿态跟随、触控、暂停、回正、近景和 D4 三维探索。由 GitHub Actions 上传该目录并部署到 GitHub Pages，不安装前端依赖，也不包含模型母版。
